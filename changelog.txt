Version 1.0.0 - January 21, 2026

NEW FEATURES
• DVD-style interface with season and episode browsing
• Support for videos, audio, images, and external executables
• Thumbnail previews for all media types
• Subtitle support with toggle functionality
• Fullscreen mode for immersive viewing
• Volume and playback controls
• Keyboard shortcuts for common actions

IMPROVEMENTS
• LRU cache for image thumbnails to improve performance
• Robust path resolution for media files and subtitles
• Automatic media duration detection
• Responsive UI layout with collapsible panels

BUG FIXES
• Fixed image scaling issues with large thumbnails
• Resolved subtitle path resolution problems
• Improved error handling for missing media files
